# WorldLab

An AI scientist runs a 12-hectare farm near Al Ain: it plants trial plots, calibrates its crop model,
plans for a bad year, trains an irrigation policy by reinforcement learning inside its own model,
and catches hidden faults during the season.

Source: https://github.com/MoAmrYehia/WorldLab

Add `MODEL_API_KEY` under **Settings → Variables and secrets** to let Muse Spark run the farm.
Without it, the scripted scientist runs.
